Entry for the make.fun bounty [How Many Tabs Do You Have Open?](https://make.fun/bounty/u-danu-how-many-tabs-do-you-have-open-d86e783d).

The program writes a single number — `347` — to `/output/entry.txt`: an honest,
lived-in tab-hoarder count. High enough to surprise a field of 5–50 tab answers,
odd and specific rather than a round number, yet believable for a heavy browser
user with many windows open. Digits only, no words, no punctuation.

Run with `node main.ts` (Node 22+). `OUTPUT_DIR` overrides the output directory
(default `/output`).
